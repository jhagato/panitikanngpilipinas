# panitikanngpilipinas
Ang Panitikan ng Pilipinas ay isang website na naglalaman ng mga akdang pampanitikan ng Pilipinas na nilikha ng mga kontemporaryong manunulat. Hinihiling na magbigay ng donasyon kung gagamitin sa hindi komersyal na gawain. Kailangang humingi ng pahintulot at magbayad para sa layuning komersyal at publikasyon.
